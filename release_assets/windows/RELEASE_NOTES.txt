SF Home Finder 0.5.1 for Windows x64

The first Windows build since 0.3.9. Everything below happened in between, and
all of it is new if you are coming from that one.

It is called SF Home Finder now. The app always called itself that while the
download said SF Housing Monitor, so people fetched one name and were greeted
by another. Your existing installation is unaffected and nothing needs
installing twice: the folder your profile and listings live in, and the sign-in
task that runs the checks, deliberately keep their old names, because renaming
those would orphan the history of everyone who already had it.

It can tell you when a newer version exists. When there is one, a line appears
in small print at the bottom of the app. Getting it is the same as installing
it: download the new release and run Install again, which keeps your deal, your
homes and your notes. This means the app now makes one request of its own, once
a day, asking GitHub whether a newer version has been released. It sends
nothing about you, not even which version you are running, and the setting
SF_HOUSING_NO_UPDATE_CHECK=1 stops it entirely.

The number beside the match slider is right, in three places it was wrong.
Raising your budget could not raise it, so asking for more money looked like it
found nothing. People splitting a home were shown a fraction of what is there,
because the rent each person pays was being read as the rent for the whole
place. And naming neighborhoods made no difference to the estimate at all.
Before you have searched anything, the slider now estimates what a search like
yours usually finds instead of sitting at nothing.

Homes that have been taken down leave the shortlist promptly, checking for new
homes by hand is limited to once a day so that no source stops answering you,
and installing no longer reports failure when it worked. That last one is a
Windows-specific fix: the installer gave up after 45 seconds, and a first start
on a full board can spend longer than that getting itself in order.

One thing macOS has that this does not: a homefinder command for the terminal.
On Windows the Install, Open, Repair, Verify and Uninstall shortcuts in this
folder are the way in, and Open is the one you will use.

SF Home Finder 0.3.9 for Windows x64

This Windows release uses the same local-only SF Home Finder application as
the macOS release. A blank install contains no housing profile, listings,
credentials, tokens, or personal paths.

The installer runs only for the signed-in Windows user. It downloads a private
Python 3.12 runtime, creates an app-owned environment under LocalAppData, and
starts the local dashboard at http://127.0.0.1:8000. It creates a normal user
sign-in task so scheduled checks can continue after the browser closes.

No optional connector blocks the account-free public-source workflow. Gmail is
read-only and needs an owner Google OAuth client plus real saved-search alerts
before individual providers are called working. Furnished Finder needs Chrome.
Facebook automation needs an optional Apify token and supports only the public
coverage described in Sources.

The ZIP is unsigned. Keep it private and only run a copy supplied by the owner.
