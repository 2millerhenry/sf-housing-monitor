SF Housing Monitor for Windows
==============================

1. Extract the ZIP first. Do not run it while it is still inside the ZIP.
2. Double-click "Install SF Housing Monitor.cmd".
3. If Windows asks for permission, choose More info, then Run anyway only if
   you received this exact ZIP from the person who made it for you.
4. The first install downloads a private Python runtime, then opens the app in
   your browser. It does not need admin rights, Python, Git, or a terminal.
5. Build Your deal, save it, and the account-free public source check starts.

The monitor runs only on this PC at http://127.0.0.1:8000. Closing the browser
does not stop it. Keep the PC awake and signed in for scheduled source checks.

Use "Open SF Housing Monitor.cmd" later. If anything feels wrong, double-click
"Verify SF Housing Monitor.cmd". It opens a private Ready Check with one clear
next action. Repair preserves your deal, listings, and connectors. Uninstall
removes the app and only removes private data if you explicitly confirm it.

Support matrix for this build
-----------------------------

- Windows 10 or Windows 11, 64-bit (x64).
- Internet access is required for the first installation and listing checks.
- Chrome is needed only for optional Furnished Finder coverage.
- Gmail and Facebook coverage are optional and require their own setup.
- This ZIP does not contain an owner's Google OAuth client. Gmail clearly shows
  the one owner setup step until that file is supplied.
- The release is unsigned. Windows may show a SmartScreen warning on first use.

Read RELEASE_NOTES.txt for the exact tested scope and connector limitations.
