{{ data_folder }}

Reading it yourself

It is an ordinary SQLite database, so any SQLite browser opens it, as does pandas.read_sql or the sqlite3 command. Three tables carry everything worth reading:

  • listings — one row per home, with its score, price, neighborhood, original_url, and whatever you marked or wrote in status and note.
  • scan_runs — one row per check, with what started it and how it ended.
  • source_runs — one row per source within a check, with how many homes it saw.

Somewhere to start:

SELECT price, neighborhood, title, original_url
FROM listings
WHERE status = 'saved'
ORDER BY price;

Two things worth knowing. If you copy the database while the app is running, take the -wal and -shm files beside it as well, or your copy will open fine and be missing the most recent homes. And the columns ending _json are this app talking to itself — their shape changes between versions, so nothing should be built on them.

For a shortlist rather than everything, the Shortlist has a Download as CSV button that exports whatever you are looking at.
