Where do I get an app password?

An app password is a code your mail provider makes for one app. It only opens mail, you can revoke it on its own, and it is not your normal password.

  • Gmail Turn on 2-Step Verification, then create an app password in your Google Account security settings.
  • iCloud Turn on two-factor authentication, then generate an app-specific password in your Apple Account settings.
  • Fastmail, Yahoo, AOL Create an app password in the account security section.
  • Outlook.com or Hotmail Not supported: Microsoft no longer allows app passwords for mail. Use Google sign-in below, or forward the alerts to another address.
Advanced: sign in with Google instead

Use this if your account cannot make app passwords, such as one on Google’s Advanced Protection. It needs a Google Cloud OAuth client supplied by whoever prepared this copy.

Four installation steps
  1. Choose Show extension folder. Repair restores it if it is missing.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the unzipped folder.
  4. Open a Furnished Finder SF housing search, click the extension, and choose Save this search & sync.

Chrome and the local monitor must be running at check time. The setup status shows the bridge version, heartbeat, and saved-search count rather than assuming installation worked.
