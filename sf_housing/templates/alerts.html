Four installation steps
  1. Choose Show extension folder. Repair restores it if it is missing.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the unzipped folder.
  4. Open a Furnished Finder SF housing search, click the extension, and choose Save this search & sync.

Chrome and the local monitor must be running at check time. The setup status shows the bridge version, heartbeat, and saved-search count rather than assuming installation worked.
